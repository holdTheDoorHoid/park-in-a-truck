# Glossary — Park in a Truck in twelve languages

Translations must use the same word for the same thing everywhere (menus, chapters, guides, data,
flyer). This page is the shared list. **English is the source.** Each language fills in its own
section below — one section per language so translators working in parallel never edit the same
lines. If a term is missing, add it to the English table AND your section, and say so in your report.

## Tone (every language)

- Plain and warm, for neighbours with no special knowledge — a community flyer, not a legal document.
- Short sentences. Everyday words. Explain a technical word once rather than avoiding it.
- Address the reader the way community materials normally do in that language (see each section).
- PiaT's own words, translated — never add advice, never drop a sentence. The site's own safety notes
  ("Note from this site, not Park in a Truck") keep their exact meaning.
- Units stay US: feet, inches, square feet, dollars. Numbers and dates are formatted by the site.

## Never translate (keep exactly as written)

- **Names:** Park in a Truck, PiaT, Thomas Jefferson University, LUSI, Philadelphia Land Bank, PHDC,
  PHS (Pennsylvania Horticultural Society), Philadelphia Water Department, PA One Call (811), RCO names,
  park names (Melon Street Park), people's names, company and product names, website names.
- **Places:** street names and addresses ("1322 N Dover St"), neighbourhood names (Mantua, Kingsessing,
  West Kensington). *Philadelphia* itself may use the language's usual spelling (Filadelfia, فيلادلفيا).
- **City data values:** zoning codes (RSA-5, CMX-2), OPA account numbers, owner names as the City lists
  them, "Property Assessment" and other on-screen labels of City websites (add a translation in brackets).
- **Codes and sizes:** park sizes A–E, part labels (BB-1), lumber sizes (2x4, 2x4x8'), screw sizes,
  scientific plant names (*Amelanchier laevis*), email addresses, phone numbers.
- **Websites that are English only** keep their name; add "(in English)" in your language after the link.

## Terms

| English | What it means / how to handle it |
|---|---|
| Park in a Truck / PiaT | The program's name. **Never translate.** Use "PiaT" only where English does. |
| toolkit | PiaT's 36-page overview book ("the Toolkit"). |
| workbook | One of PiaT's six step booklets you write in. |
| step | One of the six stages (Acquire … Sustain), plus "Start here". |
| sub-step | One task inside a step; can be marked done. |
| Mark this step done / done | The toggle at the end of each sub-step. |
| Start here · Acquire · Organize · Assess · Dream · Create · Sustain | The step names. Short verbs, used in the menu and step path. |
| vacant lot | Land with no building on it that isn't being used. |
| lot | A piece of land with an address. |
| parcel | The City's word for a lot in its property records. |
| mid-block lot / corner lot / breezeway, alley | The three kinds of lot. |
| owner (public / private) | Who owns the lot in City records. |
| zoning | The City's rules for what a lot may be used for. Codes like RSA-5 stay as they are. |
| City records / Filled in from City records | Data the site looks up from the City of Philadelphia. |
| City (of Philadelphia) | Capital C when it means the city government. |
| RCO (Registered Community Organization) | Keep "RCO"; explain it once per page. |
| Philadelphia Land Bank | Proper noun, keep. Explain once: the City agency that sells/leases public land. |
| PHDC | Philadelphia Housing Development Corporation. Keep. |
| Sheriff Sale | Public auction of a property. Keep the English name in brackets. |
| purchase / donation / lease / in-kind (use) agreement | Ways to get the right to use a lot. |
| park committee | The neighbors' group that runs the project. |
| neighbors / neighborhood | Warm, everyday words. |
| park pieces | PiaT's printed cut-out designs you lay on a drawing of your lot. |
| frame / front / back (pieces) | The three pieces of a design: the border, the entrance piece, the far piece. |
| seam (length seam, width seam) | Strips that stretch a design to fit the real lot. |
| theme: Edible · Sanctuary · Nature · Event | The four park themes. |
| size A–E | Lot size classes. The letters stay. |
| gabion (wall, bench) | A wire basket filled with stone. |
| build guide | PiaT's step-by-step furniture instructions. |
| cut list / materials & hardware / tools | Parts of a build guide. |
| 2x4, 2x4x8', BB-1 | Lumber sizes and part labels. **Never translate.** |
| full sun / part sun / shade | Sun classes from the sun study. |
| native plant · perennial · shrub · small tree · large tree | Plant list words. Scientific names never change. |
| pollinator | Bees, butterflies, birds, bats… |
| stewardship / sustain | Caring for the park over the years. |
| My park | The person's saved project (header button, page name). |
| project file | The file you save and share with your committee. |
| Plan in 3D / the planner | The 3D design tool. |
| Note from this site, not Park in a Truck | Marks the site's own safety notes. Keep the meaning exact. |
| in English | Added after links to PiaT's PDFs and English-only websites. |
| ft, in, sq ft, $ | Units stay US (no metres, no other currency). Write the unit the way the language normally writes feet/inches. |
